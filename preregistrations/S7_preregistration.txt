S7 PRE-REGISTRATION  (written 2026-10-21 18:50 Asia/Dhaka, BEFORE any S6 result was seen)
=====================================================================================

Idea: "physics-based acquisition layer" - no training.
  The diffusion model generates a clean image. A real mammogram is that image PLUS the noise of the
  acquisition chain. S5 measured that generated images have about half the real high-frequency energy
  (0.0016 vs 0.0030). S7 adds back acquisition noise from a physical noise model fitted ONLY on train-fit
  images. No generated image is used to fit anything.

Noise model (fixed now):
  Poisson-Gaussian noise-level function: sigma(I)^2 = a*I + b   (I = pixel intensity in [0,1])
  a, b fitted on the train-fit real images with pinn_physics.PhysicsNLF (the same code as S5 F2).
  Output: x_out = clip(x + sigma(x)*z, 0, 1), with z ~ N(0,1) and a fixed seed per image slot.
  No other parameter. No tuning of a, b after seeing any S7 result.

Arms (fixed now):
  S6 decides the input set G:
    - if S6 test CONFIRMED a winner  -> G = that winner
    - otherwise                      -> G = v_base (epoch-40 baseline)
  S7 compares G + noise layer  vs  G   (same images, paired).

Rule (the same as S6, fixed now):
  PASS if ALL: KID-mammo <= 0.90 x G's value, with paired-bootstrap CI of the difference < 0;
               KID-dino <= 1.00 x G's value;  recall >= G's recall - 0.05.
  Validation stage: reference = train-fit images.
  Test stage (only if validation PASS, run ONCE, fresh noise seeds): reference = TEST images.
  The test set is then used a second time in the project, so the test-stage CI is
  widened to 97.5 % (Bonferroni for 2 confirmations).

Mechanism check (descriptive only, not part of PASS):
  HF energy and saturation of G + noise layer vs real.

If validation fails: S7 is reported as a negative result. No changes to the noise model, no retry.
